# 🥭 DeepFruitVeg – Deep Learning Based Fruit & Vegetable Identification System

**DeepFruitVeg** is an AI-powered image recognition system designed to **identify fruits and vegetables** from single or multiple-object images.  
It uses **YOLO-based multi-object detection** and **TensorFlow/Keras** models for classification.  
The project provides a **web-based Flask interface** for image upload and prediction — making it simple to use for research, learning, or commercial applications.

---

## 🚀 Features

- 🍎 Detects and classifies **multiple fruits and vegetables** in a single image  
- 🧠 Uses **Deep Learning (TensorFlow 2.14)** for accurate classification  
- 🌐 Interactive **Flask Web Interface**  
- 🖼️ Supports both **single** and **multiple image predictions**  
- 📊 Displays names and counts of detected fruits and vegetables
