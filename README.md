# 🥭 DeepFruitVeg – Deep Learning Based Fruit & Vegetable Identification System

DeepFruitVeg is an AI-powered image recognition system designed to **identify fruits and vegetables** from single or multiple-object images.  
It uses for multi-object detection and **TensorFlow/Keras** models for classification.  
The project provides a web-based interface for image upload and prediction, making it simple to use for research, learning, or commercial applications.

## 🚀 Features

- 🍎 Detects and classifies **multiple fruits and vegetables** in one image.
- 🧠 Uses **Deep Learning classification (TensorFlow 2.14)**.
- 🖼️ Web interface built with **Flask** (Python backend).
- 📦 Supports **single** and **multiple image predictions**.
- 📊 Displays names and counts of detected fruits and vegetables.
